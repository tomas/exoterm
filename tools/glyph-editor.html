docs
All commands paint into the SAME cell, one after another.
Later commands overdraw earlier ones – just like the original rxvtfont.C.
Format: bits 24‑31 op, 20‑23 a, 16‑19 b, 12‑15 x1, 8‑11 y1, 4‑7 x2, 0‑3 y2.
OP names: XDrawLine(0), XFillRectangle(1), XDrawArc(2), XFillPolygon(3), XFillArc(4/5).
